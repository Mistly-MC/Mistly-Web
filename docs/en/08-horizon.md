[Horizon](https://playhorizon.dev) is an open source (MIT) rewrite of **Minecraft: Java Edition 26.3** in Rust. Mistly can download its builds and start them like any other version: the Horizon launcher is not needed.

> [!IMPORTANT]
> Horizon is **not an official product**: it is not made by Mojang or Microsoft, nor by the Mistly team. It is a young project, so expect missing features and bugs.

## Play Horizon

1. Open the version picker and turn on the **Horizon** filter.
2. Select a **build**. Builds come straight from Horizon's GitHub releases; stable versions and nightlies can be filtered.
3. Confirm with the **Choose …** button.
4. Click **PLAY**. The build is downloaded at that moment, with the progress shown in the PLAY tile.

The first launch installs Minecraft 26.3 and its Java, then prepares the build once. Several builds can be installed side by side, and an installed build can be deleted from the picker.

## Accounts

- With a **Microsoft account**, you are signed in and can join online servers.
- With an **offline account**, the game starts offline under your username.

## Logs

Horizon games show in the [console](/docs/console) like Minecraft games, and several can run at the same time.

## When Horizon doesn't start

Mistly shows the useful line of the error rather than the whole help text. If the list of builds stays empty (*Couldn't load the builds from GitHub*), GitHub could not be reached: try again a little later.
