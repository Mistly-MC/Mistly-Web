[Horizon](https://playhorizon.dev) est une réécriture open source (MIT) de **Minecraft : Java Edition 26.3** en Rust. Mistly sait télécharger ses builds et les lancer comme n'importe quelle version : le launcher d'Horizon n'est pas nécessaire.

> [!IMPORTANT]
> Horizon n'est **pas un produit officiel** : il n'est fait ni par Mojang ou Microsoft, ni par l'équipe de Mistly. C'est un projet jeune : attends-toi à des fonctions manquantes et à des bugs.

## Jouer à Horizon

1. Ouvre le sélecteur de version et active le filtre **Horizon**.
2. Sélectionne un **build**. Les builds viennent directement des releases GitHub d'Horizon ; les versions stables et les nightlies peuvent être filtrées.
3. Valide avec le bouton **Choisir …**.
4. Clique sur **JOUER**. Le build est téléchargé à ce moment-là, avec la progression dans la tuile JOUER.

Le premier lancement installe Minecraft 26.3 et son Java, puis prépare le build une seule fois. Plusieurs builds peuvent être installés côte à côte, et un build installé se supprime depuis le sélecteur.

## Comptes

- Avec un **compte Microsoft**, tu es connecté et tu peux rejoindre les serveurs en ligne.
- Avec un **compte hors-ligne**, le jeu démarre hors ligne sous ton pseudo.

## Logs

Les parties d'Horizon s'affichent dans la [console](/docs/console) comme celles de Minecraft, et plusieurs peuvent tourner en même temps.

## Quand Horizon ne démarre pas

Mistly affiche la ligne utile de l'erreur plutôt que tout le texte d'aide. Si la liste des builds reste vide (*Impossible de charger les builds depuis GitHub*), GitHub n'a pas répondu : réessaie un peu plus tard.
